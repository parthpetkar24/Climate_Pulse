## Running the pipeline

All commands must be run from the **`hyperlocal_forecaster/`** directory.

### Option A — Full pipeline (recommended)

```bash
python -m preprocessing.pipeline
```

This runs cleaning → preprocessing in one step on the daily AQI dataset.

Additional options:

```bash
python -m preprocessing.pipeline --scaler minmax          # use MinMaxScaler
python -m preprocessing.pipeline --lookback 7 --horizon 3 # 7-day lookback, 3-day forecast
python -m preprocessing.pipeline --target pm25             # forecast PM2.5 instead of AQI
python -m preprocessing.pipeline --source all             # also clean CCR hourly data
python -m preprocessing.pipeline --report-only            # quality report without saving
```

### Option B — Individual steps

**Step 1: Cleaning only**

```bash
python -m cleaning.cleaner                    # clean both daily + CCR hourly
python -m cleaning.cleaner --source daily     # daily AQI only
python -m cleaning.cleaner --source hourly    # CCR hourly only
python -m cleaning.cleaner --report-only      # report without saving cleaned files
```

**Step 2: Preprocessing only** (requires cleaned files from step 1)

```bash
python -m preprocessing.preprocessor
python -m preprocessing.preprocessor --scaler minmax --lookback 14 --horizon 7
```

**Step 3: Augmentation** (requires processed train/val/test splits from step 2)

```bash
python -m augmentation.augmentor
python -m augmentation.augmentor --lookback 14 --horizon 7
python -m augmentation.augmentor --no-noise               # sliding windows only
python -m augmentation.augmentor --noise-std 0.02         # 2 % noise level
```

## Cleaning decisions

| Issue | Action |
|-------|--------|
| "None" / "" / "na" strings | Replaced with `NaN` |
| Exact duplicate rows | Removed; count logged |
| Unparseable dates | Set to `NaT`; row **kept** (not silently discarded) |
| Out-of-range values | **Flagged** with `flag_out_of_range=True`; **not deleted** |
| All-zero measurement rows | **Flagged** with `flag_all_zero=True`; **not deleted** |
| Missing values | Reported; imputation is done in preprocessing |

Legitimate pollution spikes (e.g., PM2.5 > 500 µg/m³ during Delhi winter) are
retained and only flagged for downstream review.

---

## Preprocessing decisions

| Step | Method | Rationale |
|------|--------|-----------|
| Missing value imputation | Forward-fill → back-fill → station median → global median | Preserves temporal continuity; no invented values |
| Duplicate timestamps | Mean aggregation per (station, date) | Avoids arbitrary row selection |
| Feature scaling | StandardScaler (default) | Zero-mean, unit-variance; suited for LSTM/neural nets |
| Split | 70 / 15 / 15 chronological | No shuffle; prevents temporal leakage |
| Scaler fit | Training split **only** | Prevents data leakage into val/test |
| Lag features | 1, 2, 3, 7, 14 days | Short and medium-term autocorrelation |
| Rolling features | 3-day and 7-day mean + std | Trend and volatility context |

---

## Augmentation rationale

| Technique | Applied to | Justification |
|-----------|-----------|---------------|
| Sliding-window generation | All splits | Standard method for sequence model training |
| Gaussian noise injection | **Training only** | Improves generalisation; noise scaled per-feature so physical relationships are preserved |
| Image augmentations | — | **Not used** — physically meaningless for pollution time-series |
| SMOTE / over-sampling | — | **Not used** — daily AQI dataset is not class-imbalanced |

### Directory structure


### Architecture

| Property | Value |
|----------|-------|
| Input | `(batch, 14, 29)` — 14-day lookback, 29 features |
| Output | `(batch, 7)` — 7-day ahead AQI forecast (standardised) |
| LSTM layers | 2 stacked, hidden=64, LayerNorm on output |
| FC head | Linear(64→32) → ReLU → Dropout(0.3) → Linear(32→7) |
| Parameters | ~57k |
| Training | AdamW + ReduceLROnPlateau (factor=0.5, patience=5), MSE loss, gradient clip=1.0 |
| Early stopping | Month-stratified internal val split (20 % of train, all 12 months) |
| Device | CPU (no CUDA detected); use GPU if available |
